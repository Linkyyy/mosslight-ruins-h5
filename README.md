# 苔光遗境 / Mosslight

原创 HTML Canvas 横版动作冒险游戏：六个连通区域，火、冰、雷元素互动，探索解锁武器与能力，装备、消耗品、首领战和本地存档。支持键盘与手机横屏多指操作，所有菜单使用游戏内全屏 UI。

- 在线游戏：https://mosslight-ruins.vercel.app/
- Git 仓库：https://github.com/Linkyyy/mosslight-ruins-h5

## 本地运行

无需安装依赖或构建。直接打开 `dist/index.html`，或在仓库根目录执行：

```sh
python3 -m http.server 8080 --directory dist
```

访问 http://localhost:8080。游戏进度保存在当前浏览器的 localStorage 中。

## 操作

键盘：A/D 或左右方向键移动，空格/W/↑ 跳跃，J 攻击，K 施法，Q 切换元素，1/2 切换武器，Shift 冲刺，E 互动，R 疗愈，3/4/5 使用快捷道具，M 地图，B 背包，I 装备，H 指南，Esc 暂停，F 切换全屏。

手机：横持设备，左侧摇杆移动，右侧图标执行跳跃、攻击、施法、冲刺和互动，支持同时操作。下方一排图标切换武器、元素并使用道具；顶部打开地图、背包、手记和暂停菜单。启程会请求全屏与横屏锁定；浏览器不支持时仍铺满窗口，竖屏会暂停并提示旋转。

## 探索与战斗

- 新旅程没有武器、元素、自愈或消耗品，需要探索获得。靠近发光遗物按 E，或点击手掌图标。
- 庭院旧路可拾得短刃，上层平台唤醒火焰，深处获得回春之种；篝火恢复生命、灵息并存档。
- 回廊水池前可找到寒冰灵印。寒冰冻结水面，对岸宝箱藏有长弓。
- 书库的火焰可焚毁荆棘；矿井的雷电会沿水传导并激活灵石。
- 庭院高处的拱门通向月孢洞窟，月孢之翼解锁二段跳。
- 短刃可衔接三段连击；观察怪物和首领蓄力，以跳跃或冲刺躲开攻击。
- 背包可使用、制作消耗品并分配三个快捷道具槽；装备页可切换武器、护甲和饰物。
- 地图支持迷雾、区域目标、机关与篝火标记、拖动、缩放和定位；手记和指南可从顶部图标切换。

## 验证

需要 Node.js，无第三方测试依赖。在仓库根目录运行：

```sh
node --check dist/game.js
node --check dist/map-ui.js
node verify.cjs
node verify-map.cjs
node verify-discovery.cjs
```

检查涵盖元素机关、战斗和装备、道具消耗与制作、存档、能力发现与旧档迁移、触屏输入、横屏全屏状态及地图交互。当前验证以 DOM/Canvas 事件模拟为主，手机实机视觉和手感仍需实际设备检查。

## 部署到 Vercel

仓库根目录的 `vercel.json` 将 `dist` 作为静态输出目录，无安装和构建命令。导入仓库时选择 Other 框架，Root Directory 保持仓库根目录。`dist/vercel.json` 也支持直接从 dist 目录部署。

源码位于 `dist/`，这个目录需要提交到 Git。本地托管配置、凭证、生成压缩包和历史开发临时文件不纳入版本控制。
